# Галина — сайт-визитка мастера-парикмахера

Одностраничный лендинг: HTML + CSS + немного JS, без сборки. Откройте `index.html` в браузере.

## Структура
```
index.html        — разметка страницы
css/style.css     — стили (цвета — в переменных в начале файла)
js/main.js        — меню, анимации, форма
assets/logo.svg   — логотип-лебедь (иконка вкладки)
assets/img/       — изображения-заглушки
```

## Что заменить
- **Телефон** `+7 (999) 000-00-00` / `79990000000` — в `index.html` (поиск по `79990000000`), включая ссылку WhatsApp.
- **Telegram** — ссылка `https://t.me/username`.
- **Фото** — положите свои файлы в `assets/img/` и поменяйте пути в `index.html`
  (`hero.svg` — портрет на первом экране, `about.svg` — блок «Обо мне», `work-1…6.svg` — портфолио).
  Рекомендуемые пропорции: портреты 4:5, работы 1:1.
- **Цены и услуги** — блок `<!-- Услуги -->`.
- **Отзывы** — блок `<!-- Отзывы -->` (сейчас примеры).
- **Форма заявки** — сейчас данные никуда не отправляются; обработчик подключается в `js/main.js` (метка `TODO`).
